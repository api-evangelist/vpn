NordVPN 6.0 for Linux is coming with a cleaner, simpler way to manage your VPN connection. The update cuts down on overlapping CLI commands, makes NordWhisper the new way to use obfuscated servers, and simplifies how you connect for P2P. These changes also mean that some existing commands are going away, so if you use scripts or automations with NordVPN, you’ll need to make a few updates before switching to version 6.0.
